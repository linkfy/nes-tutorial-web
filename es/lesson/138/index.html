138. Eor absolute

añadir el opcode EOR absolute ``0x4D``.

Lección 138 de 356 · tests/chapter_01_cpu/test_138_EOR_absolute.py

Anterior: 137 Siguiente: 139

Por qué existe este paso

EOR absolute permite el OR exclusivo contra cualquier ubicación de memoria de la CPU, manteniendo la decodificación de direcciones en little-endian fuera de la primitiva de instrucción.

En este paso, después de las dos formas de página cero, añade exactamente lo siguiente a `emulator/cpu/opcodes.py`:

def eor_absolute(cpu: CPU):
    addr = absolute(cpu)
    value = cpu.bus.read(addr)
    or_e(cpu, value)

OPCODE_TABLE = {
    ...
    0x4D: eor_absolute,
}

`emulator/cpu/addressing_modes.py::absolute usa CPU.fetch_word para decodificar primero el byte bajo y luego el byte alto. El manejador lee la dirección resultante y delega el XOR y las flags Z/N en instructions.or_e`. Carry/Overflow, la memoria, X e Y permanecen invariantes; el opcode más la palabra avanza el PC tres bytes.

Concepto erróneo: la palabra en little-endian es la ubicación del valor, no el valor en sí. Fuera de alcance: los modos de EOR indexados/indirectos (139-142) y BIT (143-145).

import inspect

from emulator.bus.cpu_bus import CpuBus
from emulator.cpu import opcodes
from emulator.cpu.cpu import CPU
from emulator.memory.fake_rom import FakeROM


def make_cpu_with_rom():
    rom = FakeROM()
    rom.write(0x7FFC, 0x00)
    rom.write(0x7FFD, 0x80)
    bus = CpuBus(program_rom=rom)
    return CPU(bus), bus, rom


def test_eor_absolute_handler_exists_and_is_in_opcode_table():
    """Objective: create eor_absolute(cpu) and add 0x4D to OPCODE_TABLE."""
    assert hasattr(opcodes, "eor_absolute")
    assert callable(opcodes.eor_absolute)
    assert list(inspect.signature(opcodes.eor_absolute).parameters) == ["cpu"]
    assert opcodes.OPCODE_TABLE[0x4D] is opcodes.eor_absolute


def test_opcode_4D_eor_absolute_reads_memory_value():
    """Objective: 4D 00 02 means EOR value at RAM[$0200]."""
    cpu, bus, rom = make_cpu_with_rom()
    rom.write(0x0000, 0x4D)
    rom.write(0x0001, 0x00)
    rom.write(0x0002, 0x02)
    bus.write(0x0200, 0x0F)

    cpu.reset()
    cpu.a = 0xF0
    cpu.step()

    assert cpu.a == 0xFF
    assert cpu.pc == 0x8003
