187. Rts implícito

conectar el opcode RTS implícito $60.

Lección 187 de 356 · tests/chapter_01_cpu/test_187_RTS_implied.py

Anterior: 186 Siguiente: 188

Requisito previo: el paso 186 aportó `rts. En este paso, añade su importación y su mapeo directo en la tabla en emulator/cpu/opcodes.py`:

from emulator.cpu.instructions import rts

OPCODE_TABLE = {
    # existing entries...
    0x60: rts,
}

Opcode

0x60 -> RTS

Objetivo

añadir el opcode 0x60 a OPCODE_TABLE.

Guía para el estudiante

RTS usa direccionamiento implícito. Eso significa que el opcode no tiene bytes de operando. La instrucción obtiene toda la información que necesita de la pila de la CPU.

Ejemplo

60 -> RTS

Pasos de ejecución

1. CPU.step() fetches opcode 0x60.
2. OPCODE_TABLE dispatches directly to rts(cpu).
3. RTS pulls the return address from the stack.
4. RTS sets PC to pulled_address + 1.

Error común

No obtengas un byte de operando para RTS. Es una instrucción implícita.

Por qué existe este paso

`CPU.step ya ha consumido el único byte de opcode, y rts` obtiene su palabra de retorno de la pila, así que no hace falta ningún envoltorio ni modo de direccionamiento. Invariantes: $60 se mapea directamente a la función de un solo argumento; el despacho no consume $8001; RTS por sí sola realiza los dos desapilamientos y la actualización de PC. Concepto erróneo: no todos los opcodes requieren un manejador con nombre.

Fuera de alcance: los ayudantes de flags y BRK son los pasos 188-190; RTI y el opcode $40 son los pasos 191-192.

import inspect

from emulator.bus.cpu_bus import CpuBus
from emulator.cpu import opcodes
from emulator.cpu.cpu import CPU
from emulator.cpu.instructions import rts
from emulator.memory.fake_rom import FakeROM


STACK_BASE = 0x0100


def make_cpu_with_rom():
    rom = FakeROM()
    rom.write(0x7FFC, 0x00)
    rom.write(0x7FFD, 0x80)
    bus = CpuBus(program_rom=rom)
    return CPU(bus), bus, rom


def test_rts_implied_is_in_opcode_table():
    """Objective: opcode 0x60 is the official RTS opcode."""
    assert opcodes.OPCODE_TABLE[0x60] is rts


def test_rts_instruction_signature_takes_only_cpu():
    """Objective: RTS is implied, so rts(cpu) does not need an operand argument."""
    assert list(inspect.signature(rts).parameters) == ["cpu"]


def test_opcode_60_rts_restores_program_counter_from_stack():
    """Objective: executing opcode 0x60 returns to the address saved on the stack."""
    cpu, bus, rom = make_cpu_with_rom()
    rom.write(0x0000, 0x60)

    cpu.reset()
    cpu.s = 0xFB
    bus.write(STACK_BASE | 0xFC, 0x02)
    bus.write(STACK_BASE | 0xFD, 0x80)

    cpu.step()

    assert cpu.pc == 0x8003
    assert cpu.s == 0xFD


def test_opcode_60_rts_does_not_fetch_operand_bytes():
    """
    Objective:
    RTS is one byte long. The byte after RTS must not be consumed as an operand.

    If RTS incorrectly fetched an operand byte, stack behavior or PC behavior could
    accidentally depend on the byte at $8001. This test makes the return target
    come only from the stack.
    """
    cpu, bus, rom = make_cpu_with_rom()
    rom.write(0x0000, 0x60)
    rom.write(0x0001, 0x99)

    cpu.reset()
    cpu.s = 0xFB
    bus.write(STACK_BASE | 0xFC, 0x34)
    bus.write(STACK_BASE | 0xFD, 0x12)

    cpu.step()

    assert cpu.pc == 0x1235
    assert cpu.s == 0xFD


def test_opcode_60_rts_can_return_after_jsr_style_stack_contents():
    """
    Objective:
    JSR to a subroutine at $9000 would push return address $8002.
    RTS then returns to $8003, the instruction after JSR.
    """
    cpu, bus, rom = make_cpu_with_rom()
    rom.write(0x1000, 0x60)

    cpu.reset()
    cpu.pc = 0x9000
    cpu.s = 0xFB
    bus.write(STACK_BASE | 0xFC, 0x02)
    bus.write(STACK_BASE | 0xFD, 0x80)

    cpu.step()

    assert cpu.pc == 0x8003
    assert cpu.s == 0xFD
