348. Viewport x scanline

Декодировать горизонтальный viewport X из одного записанного состояния scanline.

Зачем нужен этот шаг

Шаг 347 выбрал две логические nametable, которые образуют горизонтальную исходную пару. Позже композитор строк также нуждается в точном пикселе, где этот scanline начинается внутри этой 512-пиксельной пары.

Записанный адрес использует тот же упакованный макет полей прокрутки, что и t

yyy NN YYYYY XXXXX

Горизонтальный viewport X использует

XXXXX          coarse X tile column
low N bit      horizontal nametable selection, vram_addr bit 10
state.fine_x   pixel offset inside the first tile

Преобразование пикселей

viewport_x = nametable_x * 256 + coarse_x * 8 + fine_x

Пример

nametable X = 1
coarse X    = 5
fine X      = 3

viewport X = 1 * 256 + 5 * 8 + 3 = 299

Почему переиспользовать decode_background_viewport_position? Существующий чистый декодер уже владеет преобразованием упакованного поля прокрутки. И t, и записанный v имеют одинаковый макет битов, поэтому повторение масок и размеров в этом рендерере создаст две реализации, которые могут расходиться.

Важные инварианты

  • горизонтальный бит nametable 10 вносит 256 пикселей
  • coarse X вносит восемь пикселей на плитку
  • fine X вносит финальное смещение пикселя 0-7
  • вертикальный nametable, coarse Y и fine Y не влияют на viewport X
  • результат остаётся внутри логического горизонтального диапазона 0-511
  • записанный адрес не отмотан снова
  • вспомогательная функция не выполняет рендеринг или доступ к памяти

Распространённое заблуждение

Записанный адрес не нуждается в другой двухплиточной коррекции. Шаг 345 уже отмотал копию v дважды перед построением BackgroundScanlineState. Повторение отмотки здесь неправильно сдвинет каждую отрендеренную строку на шестнадцать пикселей влево.

Вне области действия

  • выбор логических адресов nametable
  • композиция строк framebuffer
  • применение горизонтального переноса к пикселям назначения
  • композиция opacity-mask
  • выбор синхронизированных данных в сравнении со старым fallback уровня кадра

# emulator/rendering/ppu_background_renderer.py

# --- NEW BLOCK: DECODE ONE SCANLINE'S HORIZONTAL VIEWPORT ---
def _scanline_viewport_x(state: BackgroundScanlineState) -> int:
    viewport_x, _ = decode_background_viewport_position(
        temp_vram_addr=state.vram_addr,
        fine_x=state.fine_x,
    )

    return viewport_x

import pytest

from emulator.ppu.ppu import BackgroundScanlineState
from emulator.rendering.ppu_background_renderer import _scanline_viewport_x


def make_scanline_state(
    *,
    coarse_x: int = 0,
    coarse_y: int = 0,
    nametable_x: int = 0,
    nametable_y: int = 0,
    fine_y: int = 0,
    fine_x: int = 0,
) -> BackgroundScanlineState:
    """Pack scrolling fields into one immutable recorded scanline value."""
    vram_addr = (
        (coarse_x & 0b1_1111)
        | ((coarse_y & 0b1_1111) << 5)
        | ((nametable_x & 1) << 10)
        | ((nametable_y & 1) << 11)
        | ((fine_y & 0b111) << 12)
    )
    return BackgroundScanlineState(vram_addr=vram_addr, fine_x=fine_x)


def test_zero_recorded_scroll_starts_at_left_edge():
    """
    Objective:
    Establish the origin of the 512-pixel horizontal logical pair.
    """
    state = make_scanline_state()

    assert _scanline_viewport_x(state) == 0


@pytest.mark.parametrize("coarse_x", [0, 1, 5, 17, 31])
def test_coarse_x_converts_tile_columns_to_pixels(coarse_x):
    """
    Objective:
    Convert each selected tile column into its eight-pixel horizontal position.
    """
    state = make_scanline_state(coarse_x=coarse_x)

    assert _scanline_viewport_x(state) == coarse_x * 8


@pytest.mark.parametrize("fine_x", range(8))
def test_fine_x_adds_offset_inside_the_first_tile(fine_x):
    """
    Objective:
    Preserve pixel-level scrolling after coarse tile selection.
    """
    state = make_scanline_state(coarse_x=5, fine_x=fine_x)

    assert _scanline_viewport_x(state) == 40 + fine_x


def test_horizontal_nametable_bit_selects_right_half_of_logical_pair():
    """
    Objective:
    Include bit 10 as a 256-pixel offset rather than treating it as pair selection.
    """
    state = make_scanline_state(
        nametable_x=1,
        coarse_x=5,
        fine_x=3,
    )

    assert _scanline_viewport_x(state) == 299


def test_maximum_horizontal_fields_reach_last_logical_pixel():
    """
    Objective:
    Prove the complete horizontal state covers exactly pixel positions 0 through 511.
    """
    state = make_scanline_state(
        nametable_x=1,
        coarse_x=31,
        fine_x=7,
    )

    assert _scanline_viewport_x(state) == 511


def test_vertical_fields_do_not_change_horizontal_viewport_x():
    """
    Objective:
    Keep horizontal row positioning independent from vertical scrolling fields.
    """
    horizontal_only = make_scanline_state(
        nametable_x=1,
        coarse_x=9,
        fine_x=6,
    )
    with_vertical_fields = make_scanline_state(
        nametable_x=1,
        coarse_x=9,
        fine_x=6,
        nametable_y=1,
        coarse_y=29,
        fine_y=7,
    )

    assert _scanline_viewport_x(horizontal_only) == 334
    assert _scanline_viewport_x(with_vertical_fields) == 334
